How to use skill
Open the skill doc once to see contract and expected outputs:
SKILL.md

Use this prompt pattern in Copilot Chat:
Use skill document-section-to-simulator-module-mapping.
Inputs:

Source section file(s): <path>
Module taxonomy file: <path>
Feature-2 constraints file: <path>
Optional:
Feature-1 JSON with test_id, module_targets, protocol_or_interface
Outputs required:
Mapping report markdown
Mapping manifest json
Example with your repo:
Use skill document-section-to-simulator-module-mapping for:
Non_RT_RIC_A1_Interface_Design.md
List 1 Module Names.md
TODO-F2-simulator-tdd.md
Generate:
Required modules
Functions to create or modify
Linkage chains across modules
Verification checks
Save outputs as one mapping report and one mapping manifest.
Reuse the provided templates/rules:
Rules: mapping_rules.oran.v1.json
Report template: mapping_report_template.md
Manifest template: mapping_manifest_template.json
Schema check: output_schema.json
Improve it after each run:
Add what worked or failed in:
run_improvement_log.md
If rules change materially, create a new versioned rules file (v2, v3) and keep v1 unchanged.
