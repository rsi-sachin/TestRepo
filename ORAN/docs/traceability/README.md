# Module Traceability Matrices

This folder contains module-level traceability matrices.

## Contract

Each matrix maps:

- Requirement ID
- Source technical section
- Function or class
- File path
- Test case ID
- Conformance verdict
- Status

Status values:

- Complete
- Incomplete
- TBD

Conformance values:

- Planned
- In Progress
- Passed
- Blocked

A module cannot move to Complete unless matrix rows are complete and conformance evidence is passing.
