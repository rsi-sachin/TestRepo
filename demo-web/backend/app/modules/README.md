# Module-Oriented Backend Layout

This package introduces module-separated implementation boundaries for ORAN feature delivery.

Modules:

- non_rt_ric_a1
- o1_interface
- e2_interface
- simulators/near_rt_ric
- simulators/e2_nodes
- simulators/ran_user_intent
- simulators/info_sources
- conformance_harness

Each module must maintain requirement-to-test traceability in ORAN/docs/traceability.
